# 更新日志

> 记录面向用户的变更；接口细节与验证证据见 `docs/FLOW-AUDIT.md`。

## 未发布（2026-11-06 工作区状态）

### 安全底座

- `SECRET_KEY` 改为强制注入：未配置、使用默认值或长度不足 32 位时后端拒绝启动。
- 公开接口的用户模型去掉 `email`，只有本人接口可见自己的邮箱。
- 「每天一条」的判定改用 `Asia/Shanghai`，并新增 `UNIQUE(user_id, post_date)` 约束。
- 登录改为 **双 Token 无感登录**：15 分钟 access token + 30 天 refresh token，刷新即轮换、登出即撤销；access token 过期时前端静默续期，用户无感知。
- 登录与注册防刷：单账号 15 分钟内 8 次密码错误锁定，第 9 次返回 429 + `Retry-After`；管理端 5 次锁定 30 分钟；注册每来源 IP 每小时 60 次上限。
- 受保护接口统一 401 语义，前端区分断网 / 超时 / 401 / 403 / 429 / 5xx。

### 内容安全

- 创作模型拆成两条正交轴：`visibility`（公开 / 仅自己可见）与 `status`（正常 / 审核中 / 已隐藏 / 已删除），状态变化写入历史留痕。
- 私密创作随时可切换公开或私密，不出现在时间线、随机漫步与他人可见的任何入口，且不计入任何公开统计。
- 举报：同一用户去重、24 小时最多 20 次，**5 名不同用户举报自动进入待审**；作者可在「我的举报」里查看受理编号与处置进度。
- 拉黑：单向记录、双向隔离，可随时解除，上限 1000。
- 最小管理端：举报按对象聚合，支持忽略 / 隐藏 / 删除 / 恢复，所有处置留痕。

### 交互闭环

- 新增创作详情页 `/post/:id`；列表内容可点入，内容不存在或已被隐藏时给出明确出口。
- 首页时间线改为无限滚动；个人中心改为分页加载；随机漫步进页即抽并可「换一条」。
- 注册与自动登录拆开：自动登录失败也能跳回登录页并保留邮箱，不再卡死。
- 同一天重复发布前置拦截，并给出「去个人中心查看 / 看看别人的」出口。
- 创作生命周期补齐：发布后 24 小时内可编辑内容并显示「已编辑」；可软删除进回收站，30 天内恢复；删除不释放当天名额。
- 补写与草稿补齐：发布页可选择今天或前 3 天补写，内容自动保存在本机，刷新后连「上次选择的补写日期」一起恢复；补写内容带「补写」标记，第 4 天前补写被拒；发布成功后草稿清空、日期回到「今天」。
- 关于页新增服务状态自查：显示当前服务地址与配置来源、一键检测服务与数据库、手动重新获取地址。
- 应用内更新补齐取消安装后的重试、重启后「继续安装」、网页版不再显示原生更新按钮；安装失败原因翻译成中文可执行提示。

### 工程与运维

- `db_migrations.py` 做幂等迁移（尚未引入 Alembic）。
- 新增 `tests/run-e2e-tests.sh`：健康检查、内容安全、登录防刷、创作生命周期、双 Token 五组回归共 98 条断言，跑完自动清理测试数据。
- 随机漫步改为「先计数再随机偏移」，去掉 `ORDER BY random()` 的全表排序。
- 新增 `/api/health/ready` 就绪检查（区分进程存活与数据库可用），所有响应带 `X-Request-ID`，慢请求与失败请求写结构化访问日志。
- 清理未使用的 `backend/app/utils/`、遗留 SQLite 文件与 `deploy/.DS_Store`；图标脚本依赖写进 `tools/package.json`。
